# ORBITAL FRONTIER — установка обновлённой версии

1. Распакуйте архив в новую папку, не удаляя старый проект.
2. Откройте в VS Code папку `ORBITAL_FRONTIER_RELEASE`.
3. В терминале PowerShell выполните:

```powershell
cd webapp
npm.cmd ci
npm.cmd run build
```

4. Если сборка завершилась успешно, опубликуйте `dist` на Cloudflare Pages:

```powershell
npx.cmd wrangler pages deploy dist --project-name orbital-frontier
```

Главный экран, экспедиции, станция, корабль и остальные разделы используют общую пиксельную типографику. Отдельная вкладка «Склад» удалена: расходные предметы отображаются в инвентаре станции. Покупка ускорителей остаётся в разделе «Донат».

Полный перечень исправлений находится в `FIX_SITE_PDF_DONE.md`.


## Важно: сохранения и адрес сайта

Игровое сохранение сейчас хранится в `localStorage` браузера. У production-адреса `https://orbital-frontier.pages.dev` и у preview-адреса вида `https://<deployment-id>.orbital-frontier.pages.dev` разные хранилища браузера. Поэтому при открытии preview-адреса может показаться стартовый набор ресурсов (120 кредитов, 30 кристаллов, 30 топлива, 8 железа, 6 меди и 2 кремния), хотя прежний прогресс остаётся в браузере на основном production-домене. Для проверки старого прогресса открывай `https://orbital-frontier.pages.dev`. Не начинай новую игру и не очищай данные сайта на основном домене.
