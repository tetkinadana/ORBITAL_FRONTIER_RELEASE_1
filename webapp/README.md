# ORBITAL FRONTIER — веб-игра

Браузерная пиксельная космическая игра на React. Зачищай планеты в боях с
автоматической стрельбой и управлением персонажем, открывай сундуки с ресурсами
и чертежами (чертежи открывают рецепты усиления), побеждай боссов, собирай ДНК,
оружие, костюмы и артефакты.
Есть отдельный вертикальный экран гачи с тремя сундуками, списками возможных
наград и шестью редкостями: обычное, необычное, редкое, уникальное,
легендарное и квантовое. Коллекция и биолаборатория находятся на складе;
гильдии и реферальный бонус остаются локальной демонстрацией.

Интерфейс использует локально включённый пиксельный шрифт Pixelify Sans с
поддержкой кириллицы и жирного начертания. Шрифт входит в сборку игры и не
загружается с внешнего сайта.

## Локальный запуск

Из каталога `webapp`:

```powershell
npm install
npm run dev
```

Для проверки production-сборки:

```powershell
npm run build
npm run preview
```

## Публикация на Cloudflare Pages

1. Создай проект Pages в панели Cloudflare и подключи Git-репозиторий с игрой.
2. Укажи каталог приложения `webapp` как корневой каталог проекта.
3. Настрой сборку: команда `npm run build`, каталог результата `dist`.
4. Запусти первую сборку. Эти же параметры сборки указаны в `wrangler.toml`.

Cloudflare Pages выдаст HTTPS-адрес вида `https://<имя-проекта>.pages.dev`.
Свой домен можно подключить в настройках Pages; проверь доступность домена у
своего регистратора и DNS-провайдера.

Текущая production-версия опубликована по адресу
[`https://orbital-frontier.pages.dev/`](https://orbital-frontier.pages.dev/).
Для запуска игры из Telegram укажи этот постоянный HTTPS-адрес в настройках
Mini App бота через BotFather. Не используй `trycloudflare.com`: Quick Tunnel
ссылка временная и перестаёт работать после остановки туннеля.

VPN не нужен для самой игры: приложение не зависит от сторонних CDN, а сборка
раздаётся как статические файлы. Но доступность Cloudflare, домена и DNS
определяется сетью и провайдером пользователя, поэтому гарантировать открытие
сайта из любой сети нельзя. Публикация также требует доступа к аккаунту
Cloudflare и подключения репозитория.

## Сохранение и ограничения

Прогресс сохраняется локально в браузере и доступен на том же устройстве и в
том же профиле браузера. Это не облачный аккаунт: данные не синхронизируются
между устройствами и не связаны с базой данных Telegram-бота. Для общей
авторизации, рейтинга или синхронизации прогресса потребуется серверный API
и база данных.

Гильдии и реферальные коды сейчас являются локальной демонстрацией: приложение
не проверяет настоящих игроков и не поддерживает общий чат. Кристаллы можно
получать за победу над боссом; реальные платежи и покупка валюты не подключены.
Гача использует только демонстрационную игровую валюту. Пилот получает опыт
только за экспедиции, а требование опыта постепенно растёт с каждым уровнем.

Для полноэкранного режима нажми кнопку в шапке игры. На телефоне также можно
добавить игру на главный экран: `manifest.webmanifest` запрашивает полноэкранный
режим при запуске установленного приложения. Во время боя двигай джойстик
пальцем; на компьютере доступны WASD и стрелки.
